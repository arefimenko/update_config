# Обновление конфига VPN

Статический одностраничный сайт для GitHub Pages. Файлы обрабатываются в браузере, на сервер ничего не уходит.

## Что настроить

1. **Строки замены** — в начале `app.js`, объект `CONFIG` (`from` → `to`, отдельно для раздела 1 и 2).
2. **Фото** — положить в `img/amneziavpn/`, `img/amneziawg-lazy/`, `img/amneziawg/` с любыми именами (например `1.jpeg`, `2.jpeg`) и прописать путь в `steps.js`.
   Пока фото нет, на его месте видна заглушка с ожидаемым путём.
3. **Шаги и подписи** — в `steps.js`: для каждого раздела списки `before` (до кнопки) и `after` (после). Количество шагов любое, нумерация считается сама.

4. **После правок `style.css`, `steps.js` или `app.js`** увеличьте число `?v=…` в ссылках на них в `index.html` — иначе телефоны могут до 10 минут показывать старую версию из кэша.

## Деплой на GitHub Pages

1. Создать репозиторий и залить файлы в ветку `main`.
2. Settings → Pages → Source: *Deploy from a branch*, Branch: `main` / `(root)`.
3. Через минуту сайт будет на `https://<user>.github.io/<repo>/`.

## Локально

```bash
python3 -m http.server 8765
```
